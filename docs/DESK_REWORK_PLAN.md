# Desk polish, live data and functional gaps: match the phone's appeal, scrutinize every module

## Context
Through Wave 7b the desk matched the phone's **functions** and borrowed its **colours**, but not its **rules**. Chris's verdict from the Quote screenshot: cities don't autocomplete via Mapbox, the pills are "unsexy", it feels "underdesigned and fake luxurious", and space is filled to be filled. He wants each module scrutinized twice: layout/UX against the phone's design rules (`TRUELANE/docs/reference/DESIGN_PRINCIPLES.md`, `DESIGN_OVERHAUL_MAP.md` §3/§7/§12/§13, `DESIGN_PLAYBOOK.md`) and function against the phone so nothing is missing.

**Decisions made (Chris):** desk-owned server Mapbox module (no phone-repo edits, token server-side); keep and redesign **both** themes (night + day); match the phone's look but allow **desktop exceptions** (KPI charts, planner grid, dense tables); functional scope this round = **core load integrity, quote/assign safety checks, scorecards and exports**. Out of this round: compliance/expiry tracking, profit/margin (needs his sign-off on the definition), POD/file storage, outbound notifications and the driver bridge/auth (his Connect gate).

**Standing constraints:** desktop only (check 1440 and 1024); local commits only, Chris pushes; each wave = a check-in and a local commit; no phone-app edits; never print env values; demo DB only (`postgresql://demo:demo@localhost:54330/demo`); `tests/no-legacy.test.ts` forbids `src/app/api` and pins Prisma model names (new columns fine); ESLint bans `Number()`, `Math.round` etc. in `src/server/**`.

## Evidence (three read-only audits)
**Visual vs the phone's rules**
- Status is a filled pill: `.tl-chip` (`src/app/(desk)/desk.css:74-81`; wrappers `components/desk/ui.tsx:37-52`; labels/tones `lib/desk-format.ts:35-58`), 27 call sites, up to three pills per Loads row. Rule: *a chip is never a status; status = dot + uppercase Condensed kicker, no fill.* Tone map is muddled (healthy "Accepted" amber; "Needs a driver" steel = the at-market colour; "Assigned, not sent", the state needing action, is the quietest grey).
- Other pill families: `.al .lvl`, `.tl-pill-n` nav counts, `.dl` KPI deltas, `.tl-tab` filter/sort tabs; fixed Pickup/Delivery role labels drawn as chips.
- 15 bordered box styles; load drawer ~11 boxes + 3 trio tiles; KPI ~15; box-in-box on dispatch, planner, KPI, settings, rate-cons; `Stat` = a card per number; 4 copy-pasted inline-style kickers.
- Tokens: button 8 / card 12 / pill 999 vs press 6 / field 8 / tile 10 / note 14 / card 20; 25 `box-shadow`s (phone: none); toast side stripe; zebra rows; nested scroller `max-height: calc(100vh - 250px)`; motion 100/160/220 vs 110/200/220/320; gold used for links/tabs/chart ink (phone: the one hero value); kickers in sans not Barlow Condensed; hero `.qt-big` 26px sans, smaller than a KPI cell.
- Wasted space: page title repeated in crumb + ~24-word subtitle on every page; 760px full-page load view and 820px alerts on a 1440 canvas; centred icon+title+paragraph empty states.
- Contrast gaps: `fg-dim` on elev-3 3.87:1 / elev-2 4.40:1; `.pl-load.done {opacity:.62}` ~2.5:1; `fg-faint` 2.75:1 on a hover border; no placeholder rule; global `:focus-visible` forces radius 4; day-theme borders weak.

**Live data**
- Every address input (`quote-desk.tsx:192`, `rate-con-intake.tsx:326`, `load-actions.tsx:171`, `fleet-forms.tsx:395`) is plain text; no `src/` code calls Mapbox. Miles typed; drive time flat 50 mph (`server/tl/evaluate.ts:51,193`); rate-con time zones hard-coded `-06:00`/`-05:00` (`server/ratecon/map.ts:79-82`, wrong in DST and outside Central). `Stop.lat/lng` exist, never written; `Vehicle` has no home coordinates.
- Keys verified live: Mapbox, EIA, FMCSA, Anthropic (rate-con read verified). Only Anthropic is wired.
- Phone `lib/mapbox.ts` imports react-native (can't vendor); vendorable pure helpers: `routeLegs`, `stopRoles`, `stopTime` (+`tz-lookup`), `eiaRegion`, `appointmentWindow`, `tripHours` (already vendored). Stored geocodes must use the **permanent** endpoint; autocomplete uses the temporary one and stores nothing; use geocoding (not Search Box) for cities/addresses.

**Functional (desk vs phone)** — top gaps: a load's truck can never be set/changed after creation and rate/miles can't be corrected (only cancel, which counts as fell-through); no delete/void load; rate-con save drops weight/notes/dock/detention terms and has no duplicate guard; invoice sheet has no MC/DOT/address/remit-to and the workspace name "Demo fleet" is uneditable; Mark paid has no paid date/method; Quote prices trucks that can't haul the load (no weight/size/equipment inputs); no assign from dispatch queue/planner; no broker entity or on-time/short-pay scorecards; dead code `invoiceAction`/`markPaidAction`; `assign-fields` step 0.01 refuses 0.051; rate-con miles `step=1`; planner drops loads with no stop windows (`lib/planner.ts:91`); unbounded reads; invoice number uniqueness check outside its transaction.

## Waves (each: build, tests, browser walk at 1440/1024 in both themes, doc section, memory, local commit, check-in)

### Wave A. Design foundation (token- and primitive-level; lifts every page)
Edit once in `globals.css`, `desk.css`, `components/desk/{ui.tsx,data-table.tsx,data-table-tools.tsx,desk-shell.tsx,kit/*}`, `lib/desk-format.ts`:

2. **StatStrip** (rule-divided, label above condensed tabular number, one gold hero) replaces `Stat`, `.trio`, `.km` shell, truck floor preview; one **hero figure style** (Condensed 600, 34-48px, tabular) for quote verdict, drawer all-in, truck break-even floor, invoice/statement totals; semantic colour only on verdicts.

5. **One table** (merge `.dt` and `.tl-table`): ruled rows, no zebra, state by StatusLabel dot only, no nested scroller, sortable headers with `aria-sort`.
6. Token pass for both themes: radius roles (press 6, field 8, tile 10, note 14, card 20); hairline + lit top edge instead of shadows; motion 110/200/220/320, 0.98 press scale; `InlineNote` + tone-bordered pausable toast (no side stripe); Condensed kickers; lighter page head (drop the duplicated crumb/h1, one short sentence, one primary action); one-line empty states; day-theme borders/surfaces redone.
